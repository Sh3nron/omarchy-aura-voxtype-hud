# React Bits Strands

This plugin integrates React Bits Strands by David Haz:

https://github.com/DavidHDev/react-bits

No React Bits source code or generated port is included in this repository.
During setup, the user's machine downloads an immutable upstream revision
directly from DavidHDev/react-bits, verifies its integrity, preserves its
license, and generates Qt-compatible shaders in the user's local state folder.

Pinned upstream commit: `0e69e737242df1d257b4e5e399b01ae1d7901375`

The downloaded files and locally generated adaptations remain subject to the
React Bits license stored beside them at install time. This repository's MIT
license applies only to the independently written Omarchy integration and
conversion tooling.

As of September 2026, React Bits uses an MIT + Commons Clause license that
expressly restricts redistribution of its components as ported versions. Do
not copy the downloaded or generated files into distributions or commits. See
the upstream repository for its complete license terms.
